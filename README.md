This project makes use of
- Python
- Jupyter Notebooks

In order to start the preprocessing:
Make sure you have the dataset ready:
- Place directory atp_sources in your base directory (where preprocessing.ipynb is)
- Run the notebook "preprocessing.ipynb"

This creates the cleaned dataset: "2000-2024 players_3.csv"

Now in order to make XGBoost predictions:
- Navigate to directory "xgboost_predictions"
- Run the notebook xgboost.ipynb
